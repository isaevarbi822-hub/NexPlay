# NEXPLAY Cloud 2.0 — Ultra iPad Edition

Рабочий **статический веб-прототип игровой платформы**, рассчитанный на iPad 10-го поколения и Safari. Не является действующим аналогом GeForce NOW: пока **нет облачных игровых GPU-серверов, запуска ПК-игр, входа через Steam/Epic или прав на потоковую передачу сторонних игр**. Карточки Steam и Epic ведут к официальному поиску в соответствующих магазинах.

## Что добавлено в версии 2.0

- Два **оригинальных браузерных мини-игровых режима**: Orbit Run (управление пальцем, кнопками или геймпадом) и Memory Matrix (найти 8 пар), с сохранением локальных рекордов.
- Отдельный раздел «Играть сейчас», большие игровые баннеры и обновлённая навигация в ландшафтном и портретном режимах iPad.
- Каталог 13 карточек: 2 реально запускаются в браузере, 11 ведут на официальные магазины.
- Поиск, фильтры, сортировка по названию и магазину, избранное и история недавних просмотров.
- Автовыбор языка по `navigator.languages`, возможность ручной смены в настройках: русский, норвежский (bokmål), английский, немецкий, французский, испанский, польский. Для прочих языков — английский.
- Настройки «меньше анимации» и «компактные карточки»; они, как и избранное/рекорды, хранятся **только на устройстве** (localStorage).
- PWA manifest, иконки и service worker для открытия **уже загруженного сайта и браузерных игр** без доступа к сети после первичной установки. Доступность офлайн зависит от успешной установки/кеширования и политики Safari.
- Система использует нативный HTML/CSS/JS **без npm, внешних шрифтов, аналитики и сторонних CDN**.
- Клавиатура: `Ctrl/Cmd + K` или `/` для поиска, `Esc` для закрытия окон.

## Как запустить

**Быстрый локальный просмотр:** открой файл `index.html` рядом с `i18n.js`. Для PWA/офлайн работы нужен HTTPS-сайт. Самый простой способ — загрузить **содержимое этой папки** на Netlify как статический сайт. `netlify.toml` уже включён.

**На iPad:** открой HTTPS-адрес опубликованного сайта через Safari → кнопка «Поделиться» → «На экран „Домой“» (название зависит от языка iPad). Сайт запустится как веб-приложение. Автоматически будет выбран язык Safari; если ты в Safari отдельно менял список предпочитаемых языков, он может отличаться от основного языка iPad.

**Важное про офлайн:** попробуй открыть сайт онлайн хотя бы один раз и дождись загрузки файлов. После этого для веб-мини-игр обычно доступна офлайн-оболочка в установленной PWA. Steam/Epic магазины офлайн не работают.

## Файлы
- `index.html` — интерфейс, каталог и игровой код.
- `i18n.js` — все семь языковых пакетов.
- `sw.js` — автономная оболочка версии 2.0.
- `manifest.webmanifest` — настройки PWA.
- `icon.svg`, `apple-touch-icon.png` — иконки.
- `netlify.toml` — заголовки для хостинга.

## Следующий инженерный этап
Для настоящего облачного гейминга необходимы арендованные GPU-машины, система запуска/изоляции игровых сессий, интерактивная передача видео и управления с малой задержкой, мониторинг ресурсов, средства управления правами на игры и законное подключение игровых библиотек. В текущей версии **не взимай плату за запуск игр Steam/Epic как за работающую функцию**.
